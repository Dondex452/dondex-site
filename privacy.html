Privacy policy

Last updated: 10 November 2026

youtube-publisher is a private, single-user application. It is operated by one person, David Okeke, to upload his own videos to his own YouTube channel, @Dondex-quotes. It is not offered to the public and has no other users.

What the app accesses

  • It uploads video files and their titles, descriptions and tags to the authorised channel.
  • It reads the authorised channel's own name, ID and statistics, to confirm the connection works.

It does not read any other channel's private data, and it does not read viewer data.

What is stored, and where

An OAuth refresh token and the application's own client credentials are stored in a local configuration file on the operator's own computer. Nothing is sent to any server other than Google's own API endpoints.

Sharing

No data collected or accessed by this app is sold, transferred or shared with any third party. No advertising, analytics or tracking is used.

Google API Services

This app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data

The operator can revoke the app's access at any time at myaccount.google.com/permissions, and can delete the local configuration file. Both actions remove all data the app holds.
